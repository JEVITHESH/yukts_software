## 🛠️ Core Libraries (Python)

The system relies on a unified installation of 17 essential packages categorized below:

### 1. Networking & Utilities
- **requests** (>=2.31.0): Synchronous HTTP communications for LLM APIs.
- **httpx** (>=0.24.0): Modern HTTP client with async support.
- **python-dotenv** (>=1.0.0): Environment variable management via `.env` files.
- **aiohttp** (>=3.9.0): Async HTTP client/server for high-concurrency tasks.

### 2. LLM Integration
- **openai** (>=1.0.0): Support for OpenAI models (GPT-4/3.5) and compatible endpoints (vLLM, LM Studio).
- **anthropic** (>=0.8.0): Native support for Claude models.
- **mcp** (>=0.1.0): Model Context Protocol support for integrating remote tools.

### 3. Data Processing & Storage

- **numpy** (>=1.24.0): Scientific computing and numerical arrays.
- **sqlalchemy** (>=2.0.0): SQL Toolkit and Object-Relational Mapper (ORM).
- **psycopg2-binary** (>=2.9.0): PostgreSQL adapter for robust relational storage.
- **pymilvus** (>=2.4.0): Client for Milvus vector database, enabling long-term agent memory.

### 4. Observability & Tracing
- **opentelemetry-api/sdk** (>=1.24.0): Industry-standard distributed tracing.

## 🏗️ Supported Tools & Platforms

Yukta is designed to work seamlessly with various local and remote model providers:

### Local LLM Servers
- **Ollama**: Recommended for local inference (Qwen, Llama, Mistral).
- **vLLM**: High-performance batch inference engine.
- **LM Studio**: GUI-based local model management.
- **SGLang**: Structured generation server for complex agent logic.

### Remote/Cloud Providers
- **OpenAI**: Production-grade GPT models.
- **Anthropic**: High-reasoning Claude models.
- **Hugging Face**: Access to thousands of community-hosted models.

### Infrastructure Tools
- **PostgreSQL**: Used for structured data and relational persistence.
- **Milvus**: Vector database for RAG (Retrieval Augmented Generation) and agent memory.
- **Arize Phoenix**: Real-time console for debugging and monitoring agent traces.
